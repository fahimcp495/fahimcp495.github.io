Real-Time Stereo Matching Using Dynamic Programming

Final-year project University of Dhaka C++

Stereo matching estimates depth from a pair of camera images. I built a C++ pipeline that combines sliding-window cost aggregation with scanline dynamic programming, and compared three variants: window-only, dynamic-programming-only, and combined. I evaluated them on left-right consistency, valid-pixel coverage and temporal stability. The system runs at 15–30 frames per second on laboratory video.

I worked with a teammate under faculty supervision and took primary responsibility for implementing and evaluating the algorithms. The project was my first look at a trade-off I keep returning to: matching quality against runtime.

FINALLY: Open-Source Speech Enhancement

PyTorch Speech enhancement Inverse AI

FINALLY (Babaev et al., Samsung Research, NeurIPS 2024) is a GAN-based speech-enhancement model built on HiFi++ with a WavLM encoder. At Inverse AI I implemented it from scratch in PyTorch and released the code as open source. The repository includes three-stage training (with 16 kHz to 48 kHz upsampling), multi-GPU training with DDP, and inference scripts.
